# PicTools — Next.js starter

## Run
1. Install Node.js 20+.
2. Open this folder in terminal.
3. Run:
   npm install
   npm run dev
4. Open http://localhost:3000

Included:
- Homepage
- Image Compressor
- Image Resizer
- JPG → PNG
- PNG → JPG
- Responsive design
